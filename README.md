# Rock-Paper-Scissors Game

A classic, fully interactive **Rock-Paper-Scissors** game built using web technologies. Play against an automated computer opponent, track live scores, and see match outcomes with instant visual color updates.

## 🚀 Features
- **Interactive Choices:** Select Rock, Paper, or Scissors with hover animation effects.
- **AI Opponent:** Randomly generates computer choices for true game unpredictability.
- **Scoreboard Tracking:** Live-updating indicators keep track of user and computer scores.
- **Dynamic Feedback:** Color-coded messaging panel reveals wins (green), losses (red), and draws (blue).

## 🛠️ Tech Stack
- **HTML5:** Semantic architecture for layout.
- **CSS3:** Modern styling with Flexbox layout rules.
- **JavaScript (ES6+):** Responsive game mechanics and DOM manipulation updates.

## 📁 Project Structure
```text
├── index.html       # Game structure and layout
├── style.css        # Responsive styling and layouts
├── script.js        # Core game execution loops
└── images/          # Assets directory (Rock, paper, scissor graphics)
```

## ⚙️ Installation & Usage
1. Clone this repository locally:
   ```bash
   git clone https://github.com
   ```
2. Navigate directly into the project workspace directory.
3. Launch `index.html` inside your web browser of choice to start playing!
